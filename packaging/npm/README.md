# Hive

One terminal. Many agents.

Hive is a native terminal multiplexer for AI coding agents. This package
contains the same prebuilt `hive` and `hived` binaries as the GitHub release
for Linux, macOS, and Windows on x64 and arm64. Installation needs no lifecycle
scripts. The launcher uses Node.js, or Bun with `bunx --bun`.

Run `hive doctor` to check the installation and `hive` to start. Upgrade using
the package manager you installed it with.

See the [user guide](https://hive.codefrontlabs.com/docs/) and
[GitHub releases](https://github.com/JRH89/hive/releases).
