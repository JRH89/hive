
## Terminal scrollback

- Fixed wheel scrolling in normal terminal panes and added Shift+Page Up and Shift+Page Down. Terminal input returns the pane to the live screen. Alternate-screen applications keep their mouse and keyboard handling.
- Attach and resync replay bounded daemon history before drawing the live viewport. See [[IPC Protocol]] for the size limit.
- Verified the regression tests and drove the built TUI through a real PTY under tmux. The smoke test revealed an off-screen marker with the wheel, returned to the live screen with Shift+Page Down, detached, and recovered the marker after reattaching with Shift+Page Up.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, and `cargo test --workspace` passed. The full suite required Unix socket access outside the sandbox.
